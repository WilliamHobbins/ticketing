# Contratos compartidos
Guardar acá los contratos OpenAPI y esquemas de eventos aprobados por los cuatro integrantes.
Convenciones del equipo: JSON, prefijo `/api/v1`, rutas plurales y minúsculas, campos camelCase,
IDs UUID, fechas ISO 8601 en UTC, errores `{ "error": { "code": "...", "message": "..." } }`.
No inventar aquí contratos de catálogo/inventario/pedidos sin acordarlos en equipo.
